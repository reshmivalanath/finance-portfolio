# KPI Dashboard

This project presents a clear and interactive dashboard to track key financial and operational metrics. It helps management quickly understand business performance and identify areas that need attention.

## KPIs Included
- Revenue
- Gross Margin
- Operating Expenses
- Net Profit
- Cash Position
- Budget vs Actual KPIs
- Forecast Accuracy

## Skills Used
- Power BI (DAX, visuals, data modeling)
- Excel (data cleaning and preparation)
- Financial analysis
- Dashboard design principles

## Files Included
- KPI_Dashboard.pbix
- Data.xlsx
- KPI_Charts.png

## Outcome
This dashboard provides a visual summary of business health and supports faster, data-driven decision-making.
